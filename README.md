# CampusHub
Run: `npm install && cp .env.example .env && npm start` then open http://localhost:3000
Demo logins (password demo123): student@demo.com, organizer@demo.com
Maps: create a Google Cloud key, enable Maps JavaScript, Places and Directions APIs, set GOOGLE_MAPS_KEY in .env.
Free DB: SQLite file (campus.db). Cloud: deploy free on Render (Node web service, add a disk and set DB_PATH, GOOGLE_MAPS_KEY, JWT_SECRET).
